## 🚀 How to Run

```bash
# Clone the repository
git clone https://github.com/rafiul254/Hackerrank-problem-solutions.git

# Navigate to the folder
cd Hackerrank-problem-solutions

# Run any solution
python 25_minion_game.py
```

**Requirements:** Python 3.x (some problems use Python 2 — noted in file comments)

## 🧠 Key Concepts Practiced

- `list`, `tuple`, `set`, `dict` operations
- String manipulation and formatting
- `collections` module — `Counter`, `defaultdict`, `OrderedDict`, `deque`, `namedtuple`
- Exception handling with `try/except`
- Object-Oriented Programming — classes and operator overloading
- Built-in functions — `map()`, `filter()`, `zip()`, `any()`, `all()`, `eval()`
- Mathematical operations — `pow()`, `divmod()`, `cmath`
- Algorithmic thinking — greedy, sorting, string patterns
